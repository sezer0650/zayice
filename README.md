# Zâyiçe — Doğum Haritası

Batı ve klasik Doğu (zâyiçe / ilm-i ahkâm-ı nücûm) geleneğini birlikte gösteren, internetsiz çalışan doğum haritası uygulaması.

- Gezegen konumları [astronomy-engine](https://github.com/cosinekitty/astronomy) (MIT lisansı) ile hesaplanır ve Swiss Ephemeris ile karşılaştırılarak doğrulanmıştır.
- Bütün hesaplar cihazın içinde yapılır; girilen doğum bilgileri hiçbir sunucuya gönderilmez.
- Telefonda: Android'de Chrome ile açıp "Uygulamayı yükle", iPhone'da Safari ile açıp "Paylaş → Ana Ekrana Ekle".

Yorumlar tarihî bir sembol sisteminin geleneksel okumalarıdır; bilimsel olarak kanıtlanmış tahminler değildir. Kültürel ve tarihî inceleme amacıyla hazırlanmıştır.
